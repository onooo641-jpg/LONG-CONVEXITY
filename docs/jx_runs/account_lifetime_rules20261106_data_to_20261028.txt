WHICH PRICING PATH
  Standard = 49(M+P) + 149A;  No-Activation = 85(M+P).
  So No-Activation wins when 36(M+P) < 149A, i.e. (M+P)/A < 4.14.
  The threshold is a RATIO. Quoting it as a count of months plus
  resets is only right when exactly one funded account is earned.

     risk  XFA   M+P  ratio   Standard  No-Activation         cheaper
      250    8   130  16.25      9,447         12,935        Standard
      500   23   130   5.65     11,682         12,935        Standard
      900   53   157   2.96     17,475         15,230   No-Activation

  Both paths scale per account, so N does not move the winner --
  only how many funded accounts the plan expects to earn does.
