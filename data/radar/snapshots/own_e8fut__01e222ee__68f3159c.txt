Can I get a custom discount code for my community?
July 6, 2026
To be able to obtain affiliate commission, the user that you are referring to our company must use your custom discount code at checkout and validate it. If they use your affiliate link, the custom code will be automatically applied at checkout when making the purchase.
​To receive the custom discount code, you need to request it in the affiliate section . Before it is approved, we need to manually check it if it meets our guidelines.
The base discount code amount is 5%, but it can vary depending on the current promo.
