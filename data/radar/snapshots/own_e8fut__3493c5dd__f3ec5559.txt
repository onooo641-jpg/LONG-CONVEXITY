​ ​Key Points to understand for calculations
Each instrument might have a different Margin per 1 contract. Each Account balance has different allowed contracts (margin). Based on this, the maximum available position you can open will differ.
The basic calculation is as follows: Allowed margin / Margin per contract = size of the position
​
Example of how much you can open:
Example1: If the account has a 12 Contracts allowance, the allowed margin is $120,000
If the Margin per 1 contract is $10,000, the size you can open is 12 (For example E-mini S&P 500)
If the Margin per 1 contract is $1,000, the size you can open is 120 ( For example Micro E-mini S&P)
If the Margin per 1 contract is $2,000, the size you can open is 60 ( For example Silver)
Example2: If the account has a 8 Contracts allowance, the allowed margin is $80,000
If the Margin per 1 contract is $10,000, the size you can open is 8 (For example Euro FX)
If the Margin per 1 contract is $1,000, the size you can open is 80 (For example Micro Crude Oil)
If the Margin per 1 contract is $2,000, the size you can open is 40 ( For example Silver)
